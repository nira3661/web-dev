A. Bitwise Vault

Topic: Bitwise Operations & Math

Description

You are given an array of N integers. A vault opens if you can partition the array into two non-empty subsets such that the bitwise XOR sum of elements in both subsets are equal. Determine if it is possible.

Input Format

The first line contains T (test cases). Each test case consists of integer N, followed by N space-separated integers A₁, A₂, ..., Aₙ.

Output Format

Print YES if valid partition exists, otherwise NO. Evaluated on 15 isolated test cases (AC, WA, TLE, RE, CE).

Sample Input 1 
2
4
1 2 4 7
3
3 3 0
Sample Output 1 
YES
YES
Editorial Approach:

If the XOR sum of all numbers equals 0, the elements can always be partitioned into two identical XOR components.
