Problem Set:

Problem A: Bitwise Vault

Time: 1.0s | Mem: 256MB

Description

You are given an array of $N$ integers. A vault opens if you can partition the array into two non-empty subsets such that the bitwise XOR sum of elements in both subsets are equal. Determine if it is possible.

Input Format

The first line contains $T$ (test cases). Each test case consists of integer $N$, followed by $N$ space-separated integers $A_1, A_2, \dots, A_N$.

Output Format

Print YES if a valid partition exists, otherwise print NO.

Sample Input 1 
2
4
1 2 4 7
3
3 3 0
Sample Output 1 
YES
YES
Editorial / Solution Approach

Note that if the overall XOR sum of all elements is 0, we can always partition it into two sets of equal XOR sum. Check if $XOR(A_1 \oplus \dots \oplus A_n) == 0$.
