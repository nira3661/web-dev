🌸 A. Bitwise Vault

1.0s • 256MB

🌷 Story & Description

You are given an array of N integers. A vault opens if you can partition the array into two non-empty subsets such that the bitwise XOR sum of elements in both subsets are equal. Determine if it is possible.

🌱 Input Format

The first line contains T (test cases). Each test case consists of integer N, followed by N space-separated integers A₁, A₂, ..., Aₙ.

🎀 Output Format

Print YES if valid partition exists, otherwise NO.

Sample Input 🕊️ 
2
4
1 2 4 7
3
3 3 0
Expected Output ✨ 
YES
YES
🧁 Solution Whisper:

If the XOR sum of all elements equals 0, you can always split them evenly into two sets of equal XOR sum!
